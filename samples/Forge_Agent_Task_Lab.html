1 · Task

The agent runs through ForgeHost.ai.runTask() — Forge's existing cancellable agent loop. It receives stock guidance, your selected skills, an optional workspace, and a tool allowlist. With a workspace it also gets task_run_script: run a JS script (sandboxed Worker) to do complex computation — read/write workspace files via api.readText/api.write/api.list, run algorithms, and return a value via forge.finish. Host tools are a secondary API via forge.tools.run, still gated by host risk checks, confirmations, and native permissions.
