# Forge tiny-model loop

Use this small repair loop when building an app:

1. Write the complete app once. Keep it simple: one HTML file, inline CSS, plain JavaScript.
2. Do not repeat a function, line, or block. Do not restart a function after it has started.
3. Before returning, mentally check every function name, quote, brace, parenthesis, and loop header.
4. If the output becomes corrupted or repetitive, stop immediately and return the shortest complete working app. Never continue repeating damaged code.
5. Prefer fewer features over incomplete code. A small working app is better than a large broken app.
6. Return only the required JSON object. No Markdown, explanation, scratch text, or second attempt.

The host may stop generation when it detects repetition. That is a safety stop, not a request to continue.
