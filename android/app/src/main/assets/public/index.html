Install & start agent

Google Play Termux cannot accept RUN_COMMAND from other apps. The Forge agent is a small listener in Termux (port 8787).

1
Export agent files
Writes scripts to Download/ForgeBridge/
2
Copy install command
Paste into Termux
3
Open Termux & run it
Needs storage access once (termux-setup-storage)
4
Wait until agent is live
Forge polls automatically
bash /storage/emulated/0/Download/ForgeBridge/install.sh && forge-termux-agent --daemon
Agent: checking…

Stay running: forge-termux-agent --daemon. After reboot, run that again (or add to ~/.bashrc).

Enable RUN_COMMAND

F-Droid / GitHub Termux can run commands from Forge directly. Turn on external apps, then test.

1
In Termux: open drawer → Settings
2
Enable Allow external apps / RUN_COMMAND
3
Or set in ~/.termux/termux.properties:
allow-external-apps = true
then run termux-reload-settings
mkdir -p ~/.termux echo 'allow-external-apps = true' >> ~/.termux/termux.properties termux-reload-settings

    About Forge
    
          
    
            Forge is a host runtime. It generates sandboxed mini-apps and runs them live.
            Generated apps can use ForgeHost bridges: phone/SMS/contacts/location, on-device TTS,
            mic STT, camera/gallery, filesystem, Termux run/exec (stdout capture), share, storage, and HTTP.
            Save an app, then tap Home / Home screen to pin it to your launcher (Nova, Pixel, etc.).
